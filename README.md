# Meelad Fest 2K26 — GitHub Pages

Static GitHub Pages website for Sirajul Huda Arabic School.

## Files
- `index.html` — page shell
- `style.css` — responsive styling
- `script.js` — website logic and local preview state
- `logo-left.svg` / `logo-right.svg` — bundled logo assets

## GitHub Pages
Upload all files to the repository root, then enable **Settings → Pages → Deploy from a branch** and select the branch/folder containing these files.

### Important
This version stores admin edits/results in the browser's `localStorage`. It is GitHub Pages compatible, but it is **not a real multi-device real-time database**. For real-time results across visitors/devices, connect the app to Firebase or Supabase and use proper authentication.
