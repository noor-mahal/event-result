IMPORTANT SUPABASE SETUP

1. Open Supabase Dashboard for this project.
2. Open SQL Editor -> New query.
3. Open/copy site-settings.sql from this ZIP and run the COMPLETE SQL once.
4. Return to the website and sign in as Admin.
5. Open Admin -> Dashboard -> Public Display Settings.
6. Turn Total Result OFF or ON.

The website cannot create a Supabase table from GitHub Pages itself. The SQL must be run once in Supabase.

Result groups:
- KANZ
- Jawahar
- No participant

Selecting No participant is saved in the result and is displayed publicly as No participant.
